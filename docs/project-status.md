## 并行规则

1. 每条待办有稳定 ID（如 `MIG-UI-3`）+ 至少一个方案文档定位；口头事项不进表。
2. 车道内按方案顺序推进；跨车道依赖只在上表写一行，不隐式阻塞。
3. 同一文件区域的改动尽量不跨车道并行，避免回滚互相污染。
4. 完成即从本表移除当前一步，在 [work-log.md](work-log.md) 表格加一行，并推进“下一步”。
5. 阶段切换改顶部“当前”，并在下面追加一行记录。
