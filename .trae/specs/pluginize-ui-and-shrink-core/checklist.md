# Checklist

## 协议与站点

- [ ] 新增路径与帧全部落在 `tree_protocol`，且路径覆盖度用例满足 `coreOwned ∪ delegated == kept`
- [ ] 删除或改名任一核心路径、改编任一帧名时契约测试变红（防漂移有效）
- [ ] `ui.hello` 身份以 `plugins.yaml` 声明为准，未声明为 `runtime: ui` 的连接被拒
- [ ] 空 scope 订阅收全量；`topics[]` 过滤生效
- [ ] 订阅中转 / 执行 / 收集站均被可读拒绝
- [ ] 插件下线时订阅者收到 `state:"closed"` 及原因
- [ ] 队列溢出发出 `state:"lagged"` 且附 `from_seq`，无静默丢帧
- [ ] `station_delivery` 携带 `topic` 与 `origin_plugin_id`；UI 发布他人站被拒

## 委派

- [ ] 18 条端点由插件提供后核心实现被同批删除
- [ ] 未安装 / 停用 / 超时 / 回包非法分别返回 503 / 503 / 504 / 502 且原因可读，未出现 404
- [ ] 归属冲突整条拒收，不按启动顺序择一
- [ ] 委派信封含 `workspace_dir` / `data_dir` / `agent_id` / `team_id`
- [ ] 100MB 上传与下载走文件路径通道，核心 RSS 增幅 < 50MB，临时文件被清理
- [ ] 插件返回越界 `result_path` 被拒收

## 插件类型与依赖

- [ ] `runtime` 只有 `headless | ui` 两档；插件语言与执行形态不计入分类（任意 `command` 均可），核心无第三档、无语言分支、无语言白名单
- [ ] 旧清单中 `ui` 之外的任意 `runtime` 取值按 `headless` 解释并提示"清单待升级"，安装与启动不受阻断
- [ ] `runtime: ui` 条目共用既有安装 / 卸载 / 启停 / 热重启管道
- [ ] 两个 UI 并存、独立卸载、全停用时核心仍健康
- [ ] `UiHost` 不发 `tools/list`、不注册站点、不进入状态池
- [ ] 未实现 `tools/list` 的插件仍正常上线，且核心未因此新增工具相关接口、占位能力或专用日志
- [ ] 缺依赖时启用返回 409 与结构化 `missing_dependencies`，进程未启动
- [ ] 自动安装仅补齐缺失，不升级既有插件
- [ ] 版本区间无交集、依赖成环时均可读失败并列出原因
- [ ] 卸载被依赖项后依赖方被停用而非卸载

## 引导壳与品牌

- [ ] 零 UI 连接、仅有无法管插件的 UI、能力条目被停用，三种形态均打开引导页
- [ ] 静态声明 `plugin.manage` 不抑制引导页
- [ ] 票据二次使用返回 401；引导会话 token 仅放行插件端点且有有效期
- [ ] 引导页装回 UI 后能自动拉起并通过 `/api/meta` 提示可关闭
- [ ] 图标申报最后到达者生效，撤回后回退上一条，全部撤回回默认
- [ ] 图标闸门（体积、尺寸、目录逃逸、URL）全部拒收并可读
- [ ] 图标文件被删除后回默认并记日志，不出现破图
- [ ] 应用品牌后 exe 文件哈希不变（未改写 PE 资源）

## 日志与存储

- [ ] 日志三端点可用，尾部读取不整块载入
- [ ] 存储跨命名空间返回 403 且不泄露存在性
- [ ] `etag` 冲突返回 409；配额超限可读失败
- [ ] 存入任意二进制/JSON 可原样取回，核心不解析值

## 删除与回归

- [ ] 全仓无 `plugin_ui_manifest` / `plugin_ui_action` / `PluginUiRegistry` / `PluginUiView` / `plugin_ui_view` 残留引用
- [ ] `docs/plugin-development.md` 控件集描述已修正，并写明「站点是唯一贡献面」
- [ ] 12 项回归基线逐项通过（会话、流式、文件、PTY、Git、Spec、MCP、提问、团队、插件管理、字体主题、右栏窗口）
- [ ] 批次 G 明确不在本次范围，核心 agent 路由保持现状且已记录为独立 spec
- [ ] 每批一个提交，A–F 可直接 revert；E 片删除可整体回退
